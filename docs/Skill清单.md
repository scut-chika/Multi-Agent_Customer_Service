# 核心 Skill 清单（九要素）

> 项目：智服方舟——多智能体客服自主闭环平台　|　赛题方向：方向二 · 智能客服自主闭环　|　阶段：初赛

Skill 作为任务能力抽象层，每个 Skill 对应一类可复用任务能力，通过 AgentTeams 统一注册、按需挂载到 Worker。

## 示例：`exec.refund` 九要素详解

1. **Skill 名称**：`exec.refund`（退款执行）
2. **用途**：在方案获批后，按幂等规则调用支付网关完成退款并回写工单，作为“自动执行”环节的代表能力。
3. **输入与输出**：输入 `{ticket_id, refund_order, amount, currency, approved_by, approval_evidence, idempotency_key}`；输出 `{status: SUCCESS/FAILED, refund_txn_id, evidence, timestamps}`。
4. **调用条件**：方案 Agent 已批准且风险等级 ≤ 自动执行阈值；携带人工审批凭证（高风险时）；客户退款账户校验通过。
5. **依赖工具**：支付网关 MCP Server、工单系统 MCP Server、审计日志服务。
6. **失败处理机制**：网络/系统错误自动重试 3 次（指数退避）；幂等键冲突时查询既有结果而非重复退款；连续失败触发人工介入并生成回滚工单。
7. **安全边界**：仅接受白名单账户与预算内金额；单笔/单日额度超限必须人工审批；全程记录审计日志；密钥由 AgentTeams 密钥管理注入，不落 Prompt。
8. **复用价值**：换货、退票、改签等资金类操作可复用同一“幂等执行+证据回写+失败升级”模式。
9. **与多 Agent 协同流程的关系**：由执行 Agent 调用；上游接收方案 Agent 的批准方案，下游将执行证据交给核验 Agent；异常时通过主控 Agent 升级至人工。

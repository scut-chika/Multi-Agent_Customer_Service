# 智服方舟 · Agent 代码包运行说明

本包实现「聚合 → 分诊 → 方案 → 审批 → 执行 → 核验 → 复盘」多 Agent 自主闭环，
包含 **1 个 Leader + 6 个 Worker、7 个 Skill、5 个 MCP 参考 Server**。

## 快速开始（零依赖，已验证可运行）

仅需 Python 3.10+，**无需 Docker、无需 API Key**：

```bash
py main.py                          # 跑通示例工单（退款闭环）
py main.py --input data/examples/08_escalation.json   # 异常升级场景（低置信度转人工）
```

Windows 也可以直接：

```powershell
.\run_demo.ps1
```

运行后：

- 控制台输出协作过程（消息流）、结果摘要、全链路 Trace；
- `data/examples/闭环运行证据.txt`：运行证据（评审可查）；
- `data/examples/闭环运行trace.json`：全链路 Trace 明细（Span 级可回放）。

## 可选：接入真实大模型

设置环境变量后，分诊环节自动调用真实 LLM 增强（失败自动降级规则实现）：

```powershell
$env:DASHSCOPE_API_KEY = "sk-..."
$env:LLM_BASE_URL = "https://dashscope.aliyuncs.com/compatible-mode/v1"   # 默认值
$env:LLM_MODEL = "qwen-plus"
py main.py
```

## 部署为真实 AgentTeams（Docker 环境）

前置条件：Docker Desktop（Windows 用 WSL2）、LLM API Key、2 核 4 GB 内存以上。

```bash
# 1. 安装 AgentTeams（官方安装器）
bash <(curl -sSL https://raw.githubusercontent.com/agentscope-ai/AgentTeams/main/install/agentteams-install.sh)

# 2. 登录 Element Web，让 Manager 创建 6 个 Worker（角色见 config/agentteams.yaml）
#    Worker 身份定义：identities/identities.yaml

# 3. 启动本包的 MCP 参考 Server（5 个服务，暴露 tools/list + tools/call）
python3 -m mcp.run_servers          # 或 py src/mcp/run_servers.py

# 4. 在 AgentTeams 控制台注册 MCP 服务（config/agentteams.yaml 的 mcp_servers 段）
#    ticketing:8000 / payment:8001 / crm:8002 / kb:8003 / notify:8004

# 5. 将 skills/skills.yaml 中的 Skill 挂载到对应 Worker，作为任务能力抽象层
# 6. 以 data/examples/01_ticket.json 为输入，验证 NEW→…→CLOSED 闭环
# 7. 通过 AgentTeams 监控仪表盘查看 Worker 用量，AgentLoop 采集 Trace
```

说明：AgentTeams 是 Leader-Worker 运行时（Manager/Worker 容器、Matrix 通信、
RBAC、审批介入由平台提供）；本包提供的是**跑在 Worker 里的业务代码**：
Skill 实现、MCP 工具、编排状态机与身份配置。迁移真实企业系统时，
只需替换 `mcp/backend.py` 中的内存实现为真实 API 调用，协议层无需改动。

## 目录结构

```text
src/
├── main.py                 # 运行入口
├── run_demo.ps1 / .sh      # 一键运行脚本
├── requirements.txt        # 零第三方依赖
├── agents/                 # 1 个 Leader + 6 个 Worker（身份与附录 A 一致）
├── engine/                 # Ticket Context / 状态机 / Trace / LLM / 审批
├── skills/                 # 7 个核心 Skill 的 Python 实现（与 Skill清单.md 对应）
├── mcp/                    # 5 个 MCP 参考 Server + 客户端（HTTP，可迁移标准 MCP）
├── config/                 # AgentTeams / Skill 注册配置
├── identities/             # Agent 身份定义（机器可读）
└── data/examples/          # 样例输入输出与运行证据
```

## 常见问题

- **端口占用**：默认 8000-8004，可在 `mcp/run_servers.py` 的 `DEFAULT_PORTS` 修改。
- **控制台乱码**：入口已强制 UTF-8 输出；旧版 Windows 终端可改用 Windows Terminal。
- **幂等状态持久化**：`src/.runtime/payment.json` 保存退款幂等键状态，删除后回到全新状态。
- **Windows 部署 AgentTeams**：官方安装器为 bash 脚本，建议在 WSL2 或 Git Bash 中执行。

作品简介

项目名称

智服方舟——多智能体客服自主闭环平台

参赛信息

赛道：Agent Infra

赛题方向：方向二 · 智能客服自主闭环

参赛阶段：初赛（方向与方案设计）

正文

【问题与场景】企业客服渠道分散（邮件、在线客服、电话转写、社媒评论），重复工单率高；意图判断依赖人工；退款、换货、账户变更等跨系统执行慢；结果缺核验、经验难沉淀。

【核心解决方案】以阿里云 AgentTeams（Leader-Worker）为底座，构建「聚合→分诊→方案→执行→核验→复盘」多 Agent 自主闭环：主控 Agent 拆解编排；聚合 Agent 归一化去重；分诊 Agent 识别意图分级；方案 Agent 经 RAG 检索生成合规方案；执行 Agent 经 Skill/MCP 调用系统执行，高风险人工审批；核验 Agent 校验结果并确认满意度；复盘 Agent 沉淀知识库与 Skill。

【创新点】① 全链路闭环覆盖执行、核验与沉淀；② 审批+幂等+回滚，兼顾效率与安全；③ Skill 抽象能力、MCP 连接工具，生产可迁移；④ 轨迹可观测与离线评估。

【开放/复用价值】输出闭环模板、Skill 库与 MCP 契约，可复用于售后、IT 服务台、政务热线等场景。

【当前进展】已完成方案设计及 Identity、Skill、MCP 契约清单；复赛将部署跑通最小闭环并持续开源。
